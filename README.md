# Vanneth Tak — Portfolio

Personal portfolio website showcasing my projects, skills, and experience as a Full-Stack Developer.

🌐 **Live Website:** [https://vanneth-dev.github.io/](https://vanneth-dev.github.io/)

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Material UI (MUI)

## Run Locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deployment

Deployed with GitHub Pages using GitHub Actions.
